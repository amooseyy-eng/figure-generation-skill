# 论文科研图、流程图与技术路线图 Skill(自用)

这是一份给 Codex 使用的工作指令。它帮助 AI 从论文中标注可绘图数据与研究流程，提炼有依据的技术路线，让用户在清单中决定生成哪些图，再制作科研图、Mermaid 流程图、SVG 技术路线图、插图论文和两份可编辑的 PPT。

本仓库提供的是 skill 指令，不是独立的一键处理软件。实际处理能力取决于运行环境能否读取论文、执行代码并生成 DOCX/PDF/PPTX。DOCX 是推荐输入格式；PDF 和扫描件的限制见 [SKILL.md](SKILL.md)。所需组件按任务选择，见 [运行环境](references/environment.md)。

## 使用

1. 将整个 `paper-figure-data` 文件夹放入 Codex 的 skills 目录：设置了 `CODEX_HOME` 时使用其下的 `skills`，否则使用 `~/.codex/skills`（Windows 通常为 `%USERPROFILE%\.codex\skills`）。仅把文件夹放在普通项目目录中，不保证能通过 `$paper-figure-data` 调用。
2. 提供论文及相关附件，并要求 Codex 使用 `$paper-figure-data` 处理。
3. AI 完成标注和提取后，会提醒你查看论文项目第一层 `提取数据` 中的三份 CSV 选择清单及技术路线图候选大纲。候选默认生成；可检查附件来源，修改是否生成、顺序、图型、路线内容和插入位置，保存后回复“继续”。
4. 最终论文保存在论文项目根目录；标注版位于第一层 `输出论文`，PPT 和单张图片位于 `图片`，每张图对应的代码、输入数据和生成说明位于 `过程文件`。确需复制的原论文和附件放在项目第一层 `原始输入`。这些目录在运行开始时批量创建，不建在 skill 安装文件夹里。

选择清单是生成图像的依据。更改候选图型或标题后，AI 会按修改结果处理；更改数值或单位时，需要先与论文或附件核对。

论文引用补充表或正文数据不足时，AI 可以读取已提供的相关附件制作科研图。`科研图选择清单.csv` 会用“来源于附件”“附件文件”“附件位置”标出来源；附件内容另存 `提取数据/附件数据摘录.md`。使用附件数据的图注也会注明出处。

论文足以说明研究阶段、各阶段任务、模块关系及成果应用时，AI 会先写 `技术路线图候选大纲.md`，再把候选放入 `技术路线图选择清单.csv`。选中后交付完整的 SVG 源码和图片。路线内容取自论文，不使用占位文字。

## 输出

- 同时含黄色数据标注和蓝色流程标注的论文副本
- 插入所选科研图、流程图和技术路线图的完整论文
- 含可编辑图表数据的科研图 PPT
- 节点、连线和文字可编辑的流程图及技术路线图 PPT
- 按生成顺序编号、逐图对应的 Python 绘图脚本、Mermaid 源码或完整 SVG 代码、科研图数据 CSV、单张图片与文件索引

`过程文件/图像顺序与文件索引.csv` 将候选 ID、生成顺序号、论文图号、代码、图片和 PPT 页码对应起来。科研图代码放在 `过程文件/科研数据图/N01_FIG001`，流程图源码放在 `过程文件/流程图/N02_FLOW001`，技术路线 SVG 源码放在 `过程文件/技术路线图/N03_ROUTE001` 这样的独立文件夹。`N01`、`N02`、`N03` 是所有新增图共用的生成顺序号，示例中的候选 ID 仅用于说明命名方式。

请勿将真实论文、提取数据或运行结果直接提交到公开仓库。本文件夹的 `.gitignore` 仅对当前 Git 仓库生效；若论文项目位于另一个仓库，还需在那个仓库中排除 `原始输入/`、`提取数据/`、`输出论文/`、`过程文件/`、`图片/` 和 `临时文件/`。
